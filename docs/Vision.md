# DrillBench Vision

Version: 0.1
Date: 06 Aug 2026
Author: Rob Hamilton

## Mission

To build the easiest and most intuitive engineering platform for Bottom Hole Assembly (BHA) design, jar placement and drilling analysis.

DrillBench combines modern software design with proven oilfield engineering calculations to help drilling engineers make better decisions, faster.

---

## Target Users

- Jar rental companies
- Fishing companies
- Independent drilling consultants
- Directional drilling companies
- Tool manufacturers without proprietary engineering software

---

## Core Principles

- Engineering first
- Vendor neutral
- Fast workflow
- Clear visualisation
- Modern user interface
- Fully traceable calculations

---

## Long Term Vision

DrillBench will become a modular engineering platform.

Modules may include:

- BHA Builder
- Jar Placement
- Neutral Point
- Buckling
- Stretch
- Torque & Drag
- Hydraulics
- Reporting
- Well Database

Each module should operate from a common engineering data model.

---

## Success Criteria

An engineer should be able to:

- Build a complete BHA in minutes.
- Understand the mechanical behaviour of the string.
- Optimise jar placement.
- Compare alternative BHAs.
- Produce professional engineering reports.

## Not in Scope (Version 1)

- Real-time rig monitoring
- WITSML integration
- Rig state detection
- Cost tracking
- Well planning
- Full drilling simulator
