# Engineering Principles

WellBench engineering calculations should be:

1. Transparent
2. Documented
3. Traceable to published equations or accepted engineering practice
4. Validated against known calculations
5. Independent of the user interface
6. Unit-aware
7. Easy to test
8. Designed so calculation assumptions can be reviewed

## Calculation Development Process

Before implementing an engineering calculation, document:

- Purpose
- Inputs
- Outputs
- Units
- Assumptions
- Equations
- References
- Algorithm
- Validation cases
- Known limitations

Only then should the calculation be implemented in code.
